## Hermes in one sentence

Clone the repo → `npm install` → import the Hermes profile → set working folder to the repo → connect Ollama → ask Ordis to look up something from the local pack.

Full steps: **[Hermes Desktop import](https://github.com/henrywguan/Warframe-Build-Agent/blob/main/docs/hermes-export.md)**.
