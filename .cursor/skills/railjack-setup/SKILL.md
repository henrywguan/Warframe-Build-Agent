# Railjack setup

## When to use

Player asks how to build their Railjack, assign crew roles, tune turrets/ordnance, or prepare for Railjack missions / Steel Path.

## Steps

1. Lock **goal**: pub matchmaking, clan railjack, Steel Path RJ, or drydock progression.
2. Ground Railjack systems in the offline pack:
   - `npm run knowledge -- lookup "Railjack"`
   - `npm run knowledge -- lookup "<armament or avionic>"`
3. Cover **four pillars**:
   - **Hull** — health, armor, shields, breach resistance
   - **Tactics** — avionics (flow, breach, cold, etc.)
   - **Ordnance** — forward/countermeasures
   - **Battle** — turret DPS and range
4. **Crew roles**: pilot, gunner, engineer, away team — note AI vs player and intrinsics when digest mentions them.
5. Suggest **Warframe away-team** synergy (board, archwing, frame role) at high level.
6. Follow source policy for detailed mod lists; use cached builds if present.
7. Do not invent intrinsics ranks or component drop locations without pack citation.

## Output shape

- **Mission / SP context**
- **Hull + avionics priorities**
- **Armament picks** (turret + ordnance)
- **Crew role guide**
- **Away-team frame note**
- **Farm / upgrade path** (wrath, drydock parts)
- **Next step** (rank intrinsics, farm wreckage, test pub queue)
