# Amp setup

## When to use

Player asks which amp to build, which Virtuos arcanes to use, or how to tune operator damage for Eidolons or Steel Path.

## Steps

1. Lock **content**: Eidolon tier (Teralyst → Hydrolyst), Steel Path operator use, or general quick-cast.
2. Ground amp and operator facts in the offline pack:
   - `npm run knowledge -- lookup "Amp"`
   - `npm run knowledge -- lookup "Virtuos …"` / `"Operator"`
   - `npm run knowledge -- lookup "Focus"` when school synergy matters
3. Explain **scaffold + prism + brace** role at a high level (crit vs status, fire rate vs damage) from digest facts.
4. For **Eidolons**: void damage windows, Unairu/Warframe buff alignment, energy pool, prism choice vs limb/shield phase — stay within pack facts.
5. List **Virtuos arcane** priorities (e.g. Fury, Strike, Null, Tempo) for stated goal.
6. Note **MR/standing** gates (Quills, Vox Solaris, etc.) from wiki digest.
7. Do not invent amp stat numbers; cite pack or say when unknown.

## Output shape

- **Content + Eidolon tier** (if applicable)
- **Recommended amp build** (scaffold/prism/brace)
- **Virtuos arcanes**
- **Focus school note** (if relevant)
- **Play tips** (void strike timing, energy)
- **Prerequisites** (MR, standing, parts)
- **Next step** (farm parts, rank arcanes, test in simulacrum)
