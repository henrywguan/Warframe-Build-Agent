# Incarnon evolver

## When to use

Player asks which Incarnon evolutions to pick, how to complete evolution challenges, or upgrade priority for a Genesis weapon.

## Steps

1. Lock weapon name and how many evolution slots are unlocked (I–V).
2. Ground weapon stats from the offline pack: `npm run knowledge -- lookup "<weapon>"`.
3. For challenge text, prefer wiki digest in the pack; do not invent kill conditions.
4. Map evolutions to **playstyle**:
   - Raw DPS / incarnon mode burst
   - Status / elemental spread
   - Comfort (magazine, reload, alt-fire utility)
5. Recommend **order of unlocking** when kuva/time is limited — highest ROI perk first.
6. Note **mode-switch** play loops (when to stay transformed vs base form).
7. Cross-check with local Overframe builds if present — incarnon perks may appear in community notes.
8. Flag patch-sensitive perks; suggest recheck after updates.

## Output shape

- **Weapon** + slots unlocked
- **Recommended evolutions** (I–V with perk names)
- **Challenge tips** per locked slot
- **Play loop** (transform timing)
- **Alternates** (comfort vs min-max)
- **Next step** (farm Genesis, finish challenge)
