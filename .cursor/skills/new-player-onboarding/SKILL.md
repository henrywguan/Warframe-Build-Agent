# New player onboarding

## When to use

New or returning player asks where to start, what to focus first week, or how to avoid early mistakes.

## Steps

1. Lock platform (default **PC**), solo vs friends, and time budget.
2. Ground recommendations in accessible content — not SP min-max unless they specify.
3. Use offline pack for facts: `npm run knowledge -- lookup` for suggested frames/weapons/mods.
4. **Week-one priorities** (ordered):
   - Complete Vor's Prize → unlock modding → open star chart
   - Build one reliable frame (e.g. Mag/Volt/Excalibur path) + one AoE primary
   - Mod basics: Serration, Hornet Strike, Pressure Point, elemental pairs, Vitality
   - Unlock junctions / MR fodder — don't rush forma spend
5. Point to **live helpers** when useful: `npm run wf -- summary`, `fissures`, `alerts`.
6. Avoid overwhelming lists — max **3 next actions** at a time.
7. Mention **trading** unlocks at MR2; use `npm run market -- price` only for specific questions.
8. Follow source-policy for builds: local Overframe if cached, else simple agent-calculated starter setups.

## Output shape

- **Player context** (MR, quest progress if known)
- **This week's goals** (3 bullets max)
- **Recommended frame + weapon** (starter builds)
- **Mods to chase first**
- **What to ignore for now**
- **Live check** (optional: fissures/alerts)
- **Next step**
