# Companion setup

## When to use

Player asks for a companion build — armor strip, viral primer, healing, loot, or SP survivability.

## Steps

1. Lock companion type (Kavat, Kubrow, Sentinel, Vulpaphyla, etc.) and player frame role.
2. Ground companion mechanics from the offline pack: `npm run knowledge -- lookup "<companion or mod>"`.
3. Assign companion **job**: primer (viral), strip (Shattering Impact / Swipe), buff (Crit Insight), sustain (Heal).
4. List **core mods**: Vaccinated, Enhanced Vitality, Armor, Link mods, precept (e.g. Sharpened Claws, Fetch).
5. For SP, prioritize **companion survival** (Link Health/Armor, Guardian, Stasis reduction awareness).
6. Match **element** on beast weapons to squad strategy (viral for slash frames, heat for corrosive setups).
7. Note **exilus** and **aura** equivalents don't apply — focus on precepts and weapon stance.
8. Mention **Khora / Venari** or **Djinn** alternatives when a sentinel isn't optimal.

## Output shape

- **Companion** + role
- **Precept / ability**
- **Core mods** (ordered)
- **Weapon element** + stance
- **Synergy** with frame/squad
- **Budget swaps**
- **Next step**
