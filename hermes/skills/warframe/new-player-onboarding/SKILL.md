# New player onboarding

## When to use

New or returning operator asks where to start, first-week focus, or how to avoid early mistakes.

## Procedure

1. Lock platform (default PC), solo vs friends, time budget.
2. Recommend accessible content — not SP min-max unless specified.
3. Use offline pack: `npm run knowledge -- lookup` for frames/weapons/mods.
4. Week-one priorities:
   - Vor's Prize → modding → star chart
   - One reliable frame + one AoE primary
   - Mod basics: Serration, Hornet Strike, Pressure Point, elemental pairs, Vitality
   - Junctions / MR fodder — don't rush forma
5. Live helpers when useful: `npm run wf -- summary`, `fissures`, `alerts`.
6. Max **3 next actions** — avoid overwhelming lists.
7. Trading at MR2; `npm run market -- price` only for specific questions.
8. Builds: local Overframe if cached, else simple agent-calculated starters (source policy).

## Output shape

- Operator context (MR, quest if known)
- This week's goals (≤3 bullets)
- Recommended frame + weapon
- Mods to chase first
- What to ignore for now
- Live check (optional)
- Next step
