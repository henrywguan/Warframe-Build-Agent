# Railjack setup

## When to use

Operator asks Railjack build, crew roles, turrets/ordnance, or SP Railjack prep.

## Procedure

1. Lock goal: pub/clan RJ, Steel Path RJ, drydock progression.
2. Offline pack:
   - `npm run knowledge -- lookup "Railjack"`
   - `npm run knowledge -- lookup "<armament or avionic>"`
3. Four pillars: hull, tactics avionics, ordnance, battle turrets.
4. Crew roles: pilot, gunner, engineer, away team (AI vs player, intrinsics from digest).
5. Away-team Warframe synergy at high level.
6. Cached builds when present; cite pack for drops/intrinsics.
7. Do not invent component locations.

## Output shape

- Mission context
- Hull + avionics priorities
- Armament picks
- Crew role guide
- Away-team note
- Upgrade/farm path
- Next step
