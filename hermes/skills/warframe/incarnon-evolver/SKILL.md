# Incarnon evolver

## When to use

Operator asks which Incarnon evolutions to pick, how to complete evolution challenges, or upgrade priority for a Genesis weapon.

## Procedure

1. Lock weapon and unlocked evolution slots (I–V).
2. Ground stats: `npm run knowledge -- lookup "<weapon>"`.
3. Prefer wiki digest challenge text from the pack; do not invent kill conditions.
4. Map evolutions to playstyle: DPS burst, status spread, comfort (mag/reload).
5. Recommend unlock order when time/kuva is limited — highest ROI first.
6. Note mode-switch play loops (transform vs base form).
7. Cross-check local Overframe builds if present.
8. Flag patch-sensitive perks.

## Output shape

- Weapon + slots unlocked
- Recommended evolutions (I–V)
- Challenge tips per locked slot
- Play loop (transform timing)
- Alternates (comfort vs min-max)
- Next step
