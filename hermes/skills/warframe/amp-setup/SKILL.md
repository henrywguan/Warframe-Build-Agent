# Amp setup

## When to use

Operator asks amp build, Virtuos arcanes, or operator tuning for Eidolons or Steel Path.

## Procedure

1. Lock content: Eidolon tier, SP operator use, or general.
2. Offline pack:
   - `npm run knowledge -- lookup "Amp"`
   - `npm run knowledge -- lookup "Virtuos …"` / `"Operator"` / `"Focus"`
3. Scaffold + prism + brace roles from digest (crit/status, fire rate/damage).
4. Eidolons: void windows, buff alignment, energy, phase-appropriate prism — pack facts only.
5. Virtuos arcane priorities for goal.
6. MR/standing gates from wiki digest.
7. Do not invent amp stats.

## Output shape

- Content + Eidolon tier
- Recommended amp (scaffold/prism/brace)
- Virtuos arcanes
- Focus school note
- Play tips
- Prerequisites
- Next step
